## 项目

| 项目 | 简介 |
| --- | --- |
| [BITree 理枝](https://github.com/bitoolkit/bitree) | 面向【REDACTED】的跨平台校园工具，集中管理课表、日程、DDL、成绩、空教室和文萃导航。 |
| [yanhekit](https://github.com/bitoolkit/yanhekit) | 面向新版延河课堂的 Agent 工具包，支持录播与字幕下载、PPT 整理、笔记生成和期末复习。 |
| [BITERNET](https://github.com/bitoolkit/biternet) | 使用 Rust 和 Iced 开发的【REDACTED】校园网桌面客户端，支持登录、注销及网络使用情况查询。 |
| [biternet-go](https://github.com/bitoolkit/biternet-go) | 使用 Go 和 MyGo 开发的【REDACTED】校园网客户端，同时提供可独立使用的 Go 客户端库。 |
| [BITopology](https://github.com/bitoolkit/BITopology) | 前端运行的带 3D 无向图的场景编辑器，专门服务于新版教室导航的开发。 |
| [bitree-homepage](https://github.com/bitoolkit/bitree-homepage) | BITree 的官方网站源码，使用 Astro 和 TypeScript 构建并部署在 GitHub Pages。 |
